# Generated Content Style

Guidance produced by this skill and inside this package stays concise and project-specific.

- Prefer one-sentence purpose statements and short bullets over prose.
- Omit obvious, generic, or rarely used details that any agent could infer from the workspace.
- Keep examples short and directly relevant to the project being documented.
- Write `[No content yet.]` instead of inventing content for a section that has nothing to say.
